- [Simple Icons](https://simpleicons.org) (CC0): Claude, OpenAI y MCP (Model Context Protocol).
- Iconos de las propias aplicaciones: Apidog, MySQL Workbench y WinSCP.
- Logos de las tecnologías de «Proyectos» que no están en el anillo (`src/assets/tech/`): HTML5 y Chrome (Devicon) y Leaflet (Simple Icons).
- Iconos propios: LLM, Agentes IA y APIs REST.
